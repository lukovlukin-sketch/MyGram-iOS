# MyGram iOS (на базе Swiftgram)

Кастомный iOS-клиент Telegram на базе открытого исходного кода Swiftgram с встроенными функциями приватности и истории.

## Что добавлено поверх Swiftgram
Все настройки вынесены в самый верх экрана настроек Swiftgram (**MYGRAM: ПРИВАТНОСТЬ И ИСТОРИЯ**):
1. **Сохранять удалённые сообщения** (вкл. по умолчанию) — перехватывает серверные удаления (и в личных чатах, и в группах/каналах) и защищает их от стирания при повторной загрузке истории. В чате у таких сообщений появляется пометка `удалено · `.
2. **Сохранять историю правок** (вкл. по умолчанию) — при каждом редактировании сохраняет предыдущую версию текста локально. У сообщения появляется индикатор `✎N · `, а в контекстном меню (долгое нажатие на сообщение) — пункт **«История правок»** с датами и кнопкой копирования.
3. **Режим призрака (Ghost Mode)** — отдельные переключатели:
   - не отправлять «прочитано»;
   - не отправлять «печатает / записывает голосовое»;
   - всегда оставаться офлайн.
4. **Секунды в сообщениях** — включены по умолчанию (переключатель в разделе «Другое» настроек Swiftgram).
5. **MYGRAM: GPS И ГЕОПОЗИЦИЯ** — подмена геопозиции и Live Location с защитой от сброса:
   - **Своя точка** — любые координаты (`широта, долгота`).
   - **Заморозить текущее гео** — фиксирует текущую точку в `UserDefaults` и держит её даже после перезапуска.
   - **Прогулка по кругу** — плавное движение вокруг точки с выбором радиуса (`50 / 150 / 300 / 500 м`) и скорости (`Пешком / Велосипед / Авто`).
   - **Зацикленный маршрут** — ввод нескольких точек через `;` (`55.7558, 37.6173; 55.7600, 37.6200; ...`), плавное движение по кругу с расчётом курса.
   - **Реалистичный дрейф (2–4 м)** и **Fail-Safe защита** — при включённом Fake GPS реальные координаты и компас никогда не отправляются, а прогресс маршрута считается по реальному времени, чтобы не сбрасываться в фоне.

## Как собрать `.ipa` бесплатно в облаке (с Windows)

### Шаг 1. Получи ключи Telegram API
1. Зайди на https://my.telegram.org и войди по номеру телефона.
2. Открой **API development tools**, создай приложение (платформа **iOS**).
3. Сохрани **`api_id`** и **`api_hash`**.

### Шаг 2. Залей проект на GitHub
1. Создай новый **публичный** репозиторий на GitHub (например, `MyGram-iOS`) — для публичных репозиториев macOS-сборка в GitHub Actions полностью бесплатна.
2. В папке `MyGram-iOS` выполни в PowerShell:
   ```powershell
   git remote set-url origin https://github.com/ТВОЙ_НИК/MyGram-iOS.git
   git add -A
   git commit -m "Add MyGram features and cloud IPA build"
   git push -u origin master
   ```

### Шаг 3. Добавь секреты и запусти сборку
1. В своём репозитории на GitHub открой **Settings → Secrets and variables → Actions → New repository secret**.
2. Добавь два секрета:
   - `TELEGRAM_API_ID` — твой числовой `api_id`
   - `TELEGRAM_API_HASH` — твоя строка `api_hash`
3. Открой вкладку **Actions → Build MyGram IPA → Run workflow**.
4. Дождись завершения сборки и скачай готовый **`MyGram-sideload.ipa`** из раздела **Releases** (или Artifacts).

### Шаг 4. Установи на iPhone (бесплатно)
1. Скачай на Windows **Sideloadly** (https://sideloadly.io) или **SideStore** (https://sidestore.io).
2. Подключи iPhone по кабелю, выбери `MyGram-sideload.ipa`, введи свой Apple ID и нажми **Start**.
3. На iPhone открой **Настройки → Основные → VPN и управление устройством** и нажми «Доверять» для своего Apple ID (и включи «Режим разработчика» в **Конфиденциальность и безопасность**, если iOS попросит).
